# Changelog

## 1.1.1 (unreleased)

First public release candidate: exact planar construction, three validity checkers, a pointwise
faithfulness evaluator and the SVG figure tool. The evaluator validates the starting isometry in
exact arithmetic. Includes generic examples, regression certificates, hostile-input tests,
certificate mutations, fuzzing, figure checks and documented tool-use disclosure.

Versions 1.0.0 and 1.1.0 were private validation milestones and were never publicly released.
Their history is not part of this repository.
